
# NewsFeed

Your daily destination for the latest news, trending stories, and important updates from around the world. We bring you information across technology, business, sports, health, and entertainment to help you stay informed.


## Features

- Live previews
- Fullscreen mode
- Responsive
- Easy access
- Readable code

## Installation

Install NewsFeed with npm

```bash
  npm install NewsFeed
  cd NewsFeed
```
    
## Run Locally

Clone the project

```bash
  git clone https://github.com/atharv017/NewsFeed.git
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run dev
```


## Environment Variables

To run this project, you will need to add the following environment variables to your .env file

`VITE_NEWS_API_KEY`
